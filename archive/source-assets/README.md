# Source Asset Archive

This directory preserves the complete authoritative Poko/Loko asset pack, its extracted contents, original sprite sheets, supplied visual references, audit archive, and the final authoritative icon.

- `Poko_Loko_Asset_Pack_v1/` is the extracted authoritative pack.
- `user-supplied/Poko_Loko_Asset_Pack_v1(1).zip` is the original archive exactly as supplied.
- `user-supplied/pokoloko_authoritative_final.ico` is the final application icon.
- Runtime code uses the curated files in `public/assets/runtime/`; the full archive is not bundled into the installed application.
